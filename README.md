# RoboX
Program, control, and monitor robots built on Arduino, Raspberry Pi, Orange PI, Banana PI, BeagleBone, EV3 and other single-board computers.

System Requirements:
    Operating System: Windows 10 or newer
    Processor: 1 GHz or faster
    RAM: 2 GB minimum (4 GB recommended)
    Storage: 500 MB available space

Installation Process:
    Download the latest RoboX_setup.exe installer from the Releases section
    Run RoboX_setup.exe
    Follow the installation wizard instructions
    Launch RoboX from the Start Menu or desktop shortcut
